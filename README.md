# www.wellmind.ie

The WellMind website (Ger Boland) with the online Everyday Wellbeing journal at `/app/`.

- Website pages: `index.html`, `journals/`, styles, `script.js`, `assets/`
- Online journal: `app/` (built from the Well Mind journal-app project; edit the source there, then copy its `dist/` here)
- `.nojekyll` makes GitHub Pages serve the files exactly as they are.

Static files only; no build step.
